# CS Degree Portfolio

A collection of academic projects and coursework from my Computer Science degree, documenting some of the code I wrote along the way.

## Repository Structure

* **`cs210-cpp-investment-calculator/`**
  * A C++ command-line application that projects investment balances over time, calculating compounding interest with and without additional monthly deposits.
* **`cs300-course-planner/`**
  * A C++ course management application designed for academic advisors. The program parses CSV data into a Binary Search Tree (BST) to allow for efficient alphanumeric sorting and course lookups for their prerequisites information.
* **`cs320-contact-service/`**
  * A Java-based contact management service built to practice software testing, defensive programming and achieve high test coverage using JUnit.
* **`cs330-comp-graphics-and-visualization/`**
  * A C++ and OpenGL application that replicates a 2D image as an interactive 3D scene, featuring custom geometric modeling, texture mapping, Phong lighting, and camera navigation.
* **`cs340-client-server-development/`**
  * A full-stack application utilizing Python, Dash, and MongoDB to demonstrate client-server architecture, database indexing, and CRUD operations via an interactive dashboard to filter and locate rescue animals.
* **`cs360-weight-tracker-app/`**
  * An Android app built with Java inside Android Studio, focused on frictionless design for logging daily weight entries, tracking progress toward a goal weight, and sending SMS alerts.
